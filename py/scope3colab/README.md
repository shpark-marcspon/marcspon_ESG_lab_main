## 출력 파일 둘 (S3C-o4b, `outputs.py`)

코랩 `run_scope3_pipeline`(셀 30 `:9476`)은 엑셀 둘을 낸다: 진단용 `<base>_result.xlsx`(`result_file`)와 원본 템플릿에 회색 칸만 채운
`<base>_filled_template.xlsx`(`filled_template_file`, `build_filled_template` `:9355`). 엔진(S3C-c2)이 낸 같은 두 파일을
`--engine-result-file`·`--engine-filled-file` 로 주면 코랩 쪽 파일과 견준다(둘은 따로 줄 수 있다). 줄·칸 값 대조(`--engine-result`)와 함께 돈다.
산출 `outputs.json`(`scope3colab.outputs/1` — 경로·시각 없음, 같은 입력이면 같은 바이트)·`outputs.md`.

| 파일 | 견주는 것 | 차이 한 줄 |
|---|---|---|
| ㉠ 결과 파일 | 시트 이름·차례, 시트마다 열 이름·차례, 줄 수(값은 `rows.py` 몫) | 빠진·더한 시트마다, 같이 있는 시트 차례가 다르면 하나, 시트마다 열 목록이 다르면 하나, 줄 수가 다르면 하나 |
| ㉡ filled template | 회색 칸(원본 템플릿에서 찾은 배출계수·배출량 열의 머리 아래 칸 전부) — 코랩 ↔ 엔진, `Decimal` 같음·빈 칸 null | 칸마다 |
| ㉡ 회색 칸 밖 | 칸마다 원본 템플릿과 같은가(각 쪽). 수식 칸은 수식 글자(`=…`) — 저장 값은 보지 않음 | 칸마다(`회색 칸 밖(쪽)`·`수식 칸(쪽)`), 시트 목록이 원본과 다르면 하나 |

서식·병합·드롭다운은 견주지 않는다. 회색 열 찾기·배율·비고 열은 코랩 규칙 그대로다(`find_gray_columns`·`ef_scale`·`find_note_column`).

**회색 칸 판 `filled`**(`synthetic_filled.py`): 기존 일곱 판의 템플릿에는 「배출계수」·「배출량」 머리 열이 없어 코랩이 모든 시트를
건너뛴다(채운 칸 0 — 그 판들에서는 ㉡ 이 「회색 칸 밖 불변」만 본다). 그래서 받은 템플릿 v2.1 의 회색 열 자리(비고 바로 뒤 두 칸, 주·서브

`answers.filled.synthetic.json` 은 빈 목록), 지오코더는 부르면 멈춤. 계수 책은 나머지 판 계수 책 + `운송`·`출장_통근`.

## compare — 받은 코랩 결과 파일을 코랩 쪽으로 (S3L3, `sid:MARC-ENT-537`)

코랩을 다시 돌리지 않고 **이미 코랩이 낸 결과 파일**을 코랩 쪽 줄로 읽어 엔진 쪽과 견준다(`cli.compare_files`).

```
uv run --frozen --group scope3colab python -m scope3colab compare --colab-result-file <결과.xlsx> --engine-result <엔진.json> [--colab-filled-file <채운.xlsx> --template <원본.xlsx>] [--engine-result-file <엔진_result.xlsx>] [--engine-filled-file <엔진_filled_template.xlsx>] [--out <폴더>]
```

- 줄은 `rows.rows_from_result_xlsx`, 결과 파일 꼴은 `outputs.compare_result_files`, 회색 칸은 `outputs.compare_filled_files` 그대로다(견줌 규칙 새로 없음 —
  `Decimal` 같음·오차 0). 종료 코드는 `run` 과 같다(같음 0·차이 1·도구 실패 2). `--colab-filled-file` 과 `--template` 은 함께, `--engine-filled-file` 은
  그 둘이 있어야 한다.
- 산출: `colab.json`·`diff.md`·`outputs.json`·`outputs.md`·`run.json`, 그리고 `diff.json`(`scope3colab.diff/1`) — 차이 줄마다 그 줄의 두 쪽 갈래와
  **매핑 칸**(C3·C13 `EF매핑명`·`EF단위`, C5 `처리방법_정규화`·`바이오매스 구분`, C6 `정규화이동수단`·`이동거리(km)`·`거리왕복계수`, C7
  `정규화이동수단`·`평균통근거리(km)`·`거리왕복계수` — 그 시트·갈래의 견주는 칸에 든 것만)을 나란히 싣는다. 원인 가르기는 이 파일을 읽는 쪽(git 밖) 몫이다.
- `run.json`·`diff.md` 머리에는 입력 파일의 **sha256 과 바이트 수만** 싣는다(경로·파일 이름 글자 없음 — 받은 파일 이름에 기업명이 있다).
- 시험(`tests/test_compare_files.py`)은 지은 파일만 쓴다. 받은 파일을 읽는 시험은 두지 않는다.
